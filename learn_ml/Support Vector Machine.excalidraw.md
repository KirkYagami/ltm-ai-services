Support Vector Machines (SVM) is a versatile machine learning algorithm that can be used for both classification and regression problems. In classification tasks, we use a Support Vector Classifier (SVC), while for regression tasks, a Support Vector Regressor (SVR) is employed. ^DJzUnBH9

A Support Vector Machine (SVM) is a supervised machine-learning algorithm primarily used for classification, although it can also perform regression. ^Fzt53h4k

At its core, SVM tries to solve a simple problem: ^RfXEgBc8

Find the best possible boundary that separates different classes of data. ^Tko0CxUl

In real-world data, it is common for classes to overlap, leading to classification errors. To address this, SVC introduces the concept of soft margin, allowing some misclassification or overlap in the data to achieve a better generalization for unseen data. On the other hand, a hard margin exists when the data is perfectly separable, without any errors, which is less common in practical applications. ^h9obpVaY

This balance between maximizing the margin and allowing for some errors is what makes SVC powerful in handling complex classification tasks. ^p3niKwQN

A hyperplane is a flat decision boundary that has one dimension less than the space in which the data exists. ^HjBmdOv0

If you just want a decision boundary that separates two classes, there are infinitely many lines/hyperplanes that would do the job — a whole family of them, tilted at different angles, positioned in different spots.

Prediction only uses the final boundary, sure, but which boundary you pick matters enormously for how well the model generalizes to new, unseen data. ^FUk1AORl

The margin and support vectors aren't used during prediction. They're what determines which specific boundary you end up with in the first place. SVM's whole idea is: ^Uodvsv6l

Among all the boundaries that separate the classes, pick the one that's as far as possible from the closest points of each class. ^R2zSOW3m

Why maximizing the margin matters ^eIr8shRI

A boundary that barely squeezes between the classes (small margin) is more sensitive to noise — a slightly different new point close to training data could easily land on the wrong side. ^11rX6zCi

A boundary with a wide margin has more "breathing room" — it's more robust to small variations or noise in new data, generally leading to better generalization. ^M5zmdsxj

Why support vectors specifically, not all points ^G71RFyvn

Once the max-margin boundary is found, it turns out only the closest points (the support vectors) actually determine its position and orientation. Every other point — the ones far from the boundary — could be moved around or even deleted, and the boundary wouldn't change at all. So: ^AyvXE6mQ

Support vectors = the training points that define the whole model, i.e., they determine w and b. ^0a8h5bNd

Everything else in the training set is "used" during the search, but ends up irrelevant to the final answer. ^jz2mVHdW

"C is the regularization parameter of SVM. It controls the trade-off between maximizing the margin and penalizing margin violations. A large C heavily penalizes violations, encouraging the model to fit the training data more strictly, while a small C tolerates more violations in favor of stronger regularization and potentially a wider margin. In scikit-learn's SVC, the default value is C=1.0, and it is usually tuned using cross-validation." ^kyRzOvTX

Gamma controls how quickly RBF similarity decreases as the distance between observations increases. ^9irZ07q7
